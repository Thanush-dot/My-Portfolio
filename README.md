🌐 Personal Portfolio Website
This is my personal portfolio website built using React.js and Tailwind CSS, showcasing my skills, projects, education, and contact details.

✨ Features
About Section – Introduction with personal branding.
Projects Section – Showcasing my machine learning model (Heart Stroke Prediction) and an E-commerce Platform.
Cloned Websites Section – Carousel slider of websites I cloned.
Skills Section – Highlights programming languages, web technologies, and tools.
Education Timeline – Interactive vertical timeline of my education journey.
Contact Section – Integrated Google Maps, contact form, and social links.
Responsive UI – Fully responsive with animations and modern design.

🛠️ Tech Stack
Frontend: React.js, Tailwind CSS
Icons & Animations: React Icons, Lucide React, Tailwind Animations
Version Control: Git, GitHub
Design Tools: Figma
